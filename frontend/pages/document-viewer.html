B.TECH. (SEM III) THEORY EXAMINATION 2023-24

Subject: DATA STRUCTURES (KCS-301) Max Marks: 100 • Time: 3 Hours

SECTION A (Attempt All Questions — 10 x 2 = 20 Marks)

Q1. (a) Define asymptotic notations Big-Oh (O), Omega (Ω) and Theta (Θ). State their formal definitions.

Q1. (b) Why is a circular queue preferred over a linear queue? Write the formula for full queue condition.

Q1. (c) Differentiate between Array and Singly Linked List with respect to random access and cache locality.

Q1. (d) Convert the following infix expression into postfix using Stack: (A + B) * (C - D) / E.

Q1. (e) What is a full binary tree vs complete binary tree? State the maximum nodes at height h.

SECTION B (Attempt Any Three Questions — 3 x 10 = 30 Marks)

Q2. (a) Write a detailed C++ algorithm to insert and delete an element from a Doubly Linked List. Trace with an example of 5 nodes.

Q2. (b) Explain the Tower of Hanoi problem with 3 disks. Write recursive pseudocode and solve its recurrence relation: T(n) = 2T(n-1) + 1.

Q2. (c) Construct an AVL tree by inserting the following sequence: 50, 20, 60, 10, 8, 15, 32, 46, 11, 48. Clearly specify LL, RR, LR, and RL rotations.

SECTION C (Long Answer / Numerical Section — 5 x 10 = 50 Marks)

Q3. Apply Dijkstra's Single Source Shortest Path Algorithm on a directed graph with 6 vertices. Show step-by-step distance table updates.

Q4. Explain B-Tree of order m. Show step-by-step creation of a B-Tree of order 5 with keys: 1, 12, 8, 2, 25, 6, 14, 28, 17, 7, 52, 16, 48.
